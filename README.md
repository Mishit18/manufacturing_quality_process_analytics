# Manufacturing Quality and Process Bottleneck Analytics

Manufacturing analytics case study for operations, strategy, and data analytics roles. The project creates a reproducible plant-quality dataset and analyzes **SPC control breaches**, **OEE**, bottleneck assets, defect drivers, scrap-cost exposure, and recommended maintenance actions.

The main external benchmark uses **UCI MetroPT-3**: 1,516,948 real operational readings from a metro-train air compressor, with chronological anomaly monitoring evaluated against four company-reported air-leak windows (DOI `10.24432/C5VW3R`). Supervised model portability is checked separately on the real **UCI Steel Plates Faults** dataset (1,941 records, 27 features, 7 fault classes; DOI `10.24432/C5J88N`). A 52,000-row simulated plant scenario remains only for OEE and SPC fields unavailable in the public datasets.

## What This Demonstrates

- Manufacturing process analytics beyond e-commerce/customer data
- SPC control charts and exception monitoring
- OEE decomposition across availability, performance, and quality
- Bottleneck scoring across defect rate, downtime, and OEE loss
- Root-cause analytics using interpretable defect-driver modeling
- Dashboard-ready CSV outputs and executive recommendation memo
- Independent validation on a real, CC BY 4.0 industrial defect dataset
- Chronological anomaly monitoring on 1.52M real MetroPT-3 sensor readings
- Class-level diagnostics, SHAP attribution, and explicitly modeled failure-priority scoring on the real dataset
- Streamlit command center separating simulated operations KPIs from real-data model evidence

## Resume Bullets

- Analyzed **1.52M real MetroPT-3 sensor readings**; built chronological anomaly monitoring against four reported compressor air-leak events.
- Validated defect classification separately on **1,941 real UCI steel-plate records** across seven fault classes; reported held-out accuracy, balanced accuracy, and macro-F1.
- Ranked line-machine bottlenecks using downtime, defect rate, scrap cost, and OEE loss; generated dashboard-ready exception tables and management recommendations.
- Trained interpretable defect-risk model and used permutation importance to link tool age, vibration, cycle time, and process conditions to quality failures.

## Data Provenance

- Predictive-maintenance benchmark: real UCI MetroPT-3 operational sensor data, CC BY 4.0.
- Operations/OEE/SPC case: simulated data generated by this repository and explicitly labeled.
- External defect benchmark: UCI Steel Plates Faults, CC BY 4.0.
- No bullet or report should describe the simulated operations data as live plant data.
